# Some Notes

## Common

`not_encode_rn` means the model uses 0/1 to represent `is_last_round`.

Default uses the round number (`rn`).

## Logs

Name: `[Algorithm]_[model]_[players]_[rounds]`

`st` is the short for `set_transformer`.

`gt` is the short for `ground_truth`.
