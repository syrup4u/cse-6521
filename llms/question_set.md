### Primary Backup Protocol

Assume you are a specialist in designing consistency protocols for distributed systems.

Now I want to implement a protocol that can satisfy my demands. There are some basic rules that you can assume they exist in an emulated distributed environment. You don't need to implement such simulator and state machines.

Basic rules (you don't need to implement this part, they are guaranteed by the simulator):

1. The environment will ensure there are at least three nodes (or more nodes), and there can be multiple rounds to reach a consensus.
2. In each round, every node will broadcast its state to all other nodes. If a node crashes in this round, it may broadcast its state only to some or none of other nodes. Already crashed nodes will never recover thus they will not broadcast their states in the future rounds. Nodes may crash at any round.
3. All nodes start with initial states.
4. Once a node sends its state to other nodes, the message will not be modified or lost in the middle.
5. We only consider the states of live nodes at last to verify the correctness of the protocol.

Protocol requirements:

1. Two initial states: local_zero, local_one. Two final states: commit_zero, commit_one.
2. All live nodes must reach final states.
3. No final states contradicts any other final states, i.e., commit_zero and commit_one cannot exist simultaneously.
4. A final state must have corresponding initial state, i.e., if there is no local_zero in all initial states, then commit_zero should not exist in all final states.

**Give me the Python code of such protocol that can work**. You can assume that I have already had a simulator that can create state machines and do the transition based on your protocol, so you only need to provide a `transition` function. Besides, all possible cases (different initial states / crashed nodes at any round / message patterns) will be generated by me to verify your protocol. But you should define the state yourself since this protocol is designed by you, and the state should be derived from this `AbstractState`:

```py
from abc import abstractmethod, ABC, ABCMeta
from enum import Enum, EnumMeta

class AbstractStateMeta(ABCMeta, EnumMeta):
    pass

class AbstractState(ABC, Enum, metaclass=AbstractStateMeta):
    @property
    @abstractmethod
    def is_initial(self) -> bool:
        """Indicates whether the state is an initial state."""
        pass

    @property
    @abstractmethod
    def is_final(self) -> bool:
        """Indicates whether the state is a final state."""
        pass

    @classmethod
    @abstractmethod
    def get_lost_state(cls) -> 'AbstractState':
        """Returns the state that represents a lost condition."""
        pass

    @classmethod
    @abstractmethod
    def get_initial_states(cls) -> list['AbstractState']:
        """Returns a list of all possible initial states."""
        pass

    @classmethod
    @abstractmethod
    def get_final_states(cls) -> list['AbstractState']:
        """Returns a list of all possible final states."""
        pass
```
